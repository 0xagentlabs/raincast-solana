# RainCast

Solana Devnet 天气预测市场 Demo。用户预测上海指定时间是否达到 0.1 mm 降水；Open‑Meteo 数据由受控预言机签名并用于链上结算。

> 仅供技术演示。使用 Devnet 测试 SOL，不构成博彩或投资服务。

## 快速开始

```bash
pnpm install --ignore-scripts
pnpm --dir app dev
```
