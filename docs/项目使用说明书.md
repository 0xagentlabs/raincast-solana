# RainCast 项目使用说明书

## 项目简介

RainCast 是部署在 Solana Devnet 的天气预测市场 Demo。用户可选择上海、北京、广州、深圳、成都、杭州、武汉或西安，用测试 SOL 预测当地未来 30 分钟内是否下雨；市场开放预测 25 分钟，截止后不再接受下注，第 30 分钟由授权预言机读取 Open‑Meteo 数据并签名结算。平台从奖池收取 1%（向下取整），其余资金按获胜侧份额全部分配，最后一名领取者获得除法舍入余数；若获胜侧无人下注，则不收费且所有参与者取回本金。同一城市不能创建时间重叠的市场，不同城市可同时开市。

该 Demo 的数据是真实天气 API 数据，但预言机发布者是单一受控签名者，并非完全去中心化。不可用于真实资金。

## 架构与目录

- `program/`：Rust + Pinocchio 链上程序。
- `app/`：Next.js App Router、Wallet Adapter 和显式 ABI 客户端。
- `oracle/settle.ts`：可选 CLI 结算工具；网页已内置运营方结算界面。
- `scripts/initialize.ts`：初始化 config PDA 与预言机公钥。
- `tests/`：TypeScript ABI/PDA 测试；Rust 单元测试位于程序源码。
- `ABI.md`：tag、二进制参数、账户顺序、PDA 和错误码。

## 环境与安装

需要 Rust、Solana CLI 4.x、`cargo-build-sbf`、Node.js 20+ 与 pnpm。仅配置 Devnet：

```bash
solana config set --url devnet
solana config get
solana address
solana balance
pnpm install --ignore-scripts
```

本地启动：`pnpm --dir app dev`，打开 `http://localhost:3000`。钱包必须切换至 Devnet。

## 页面操作

1. 钱包切换至 Devnet并连接。
2. 在“预测城市”选择框选定城市，再点击创建按钮；页面把该城市的经纬度编码进 CreateMarket，25 分钟后封盘、30 分钟后可结算。当前城市已有尚未到期的市场时创建按钮会禁用，并由该城市的链上 schedule PDA 再次校验；切换到其他城市仍可创建并行市场。
3. 在市场卡片选择 YES 或 NO，每次投入 0.01 Devnet SOL。
4. 到达结算时间后，连接 Oracle 钱包 `Dy6m…jToL`；页面显示“已验证：运营方钱包”。
5. 点击“获取天气并签名结算”，核对钱包交易并签名；其他钱包无法通过合约权限校验。
6. 市场卡片会显示当前钱包的 YES/NO 份额；结算后获胜用户点击“领取收益”。
7. Config authority `Dy6m…jToL` 连接钱包后，页面会根据链上地址自动切换为独立“平台管理面板”，不再显示预测市场操作；可在面板中点击“领取全部收益”，一次性提取 config PDA 中高于租金豁免余额的全部累计平台费。

完整参数和账户顺序以 `ABI.md` 为准。客户端在 `app/lib/program.ts` 显式编码，不使用 Anchor IDL。

## 天气数据与结算

预言机根据市场账户内的经纬度动态请求 Open‑Meteo。以下为上海市场示例：

```text
https://api.open-meteo.com/v1/forecast?latitude=31.13&longitude=121.47&current=precipitation&timezone=Asia%2FShanghai
```

脚本校验 HTTP 状态、数值类型及范围，再以预言机密钥签名。合约校验 config PDA、oracle signer、市场状态、结算时间、观测时间不得来自未来且不得超过 48 小时。私钥文件在 `.gitignore` 中，禁止提交或打印。

CLI 备用方式：`ORACLE_KEYPAIR=/安全路径/operator.json pnpm oracle:settle -- <MARKET_PDA>`。网页结算不上传私钥，由钱包扩展直接签名。

## 常见错误

- `InvalidTime`：截止/结算时间不合法，或下注已经截止。
- `InvalidAuthority`：提交结算的钱包不是 config 中记录的 oracle。
- `ObservationStale`：未到结算时间，或观测时间过旧/来自未来。
- `MarketOverlap`：上一市场尚未到期，不能创建时间重叠的新市场。
- `NoWinnings`：当前钱包没有获胜份额。
- RPC 429：更换可靠的 Devnet RPC 后重试，不要切换至 mainnet-beta。

## 安全注意事项

链上会校验 signer、writable、owner、数据长度、PDA、时间和算术溢出。天气 API 本身与授权预言机仍是信任点；生产版本应使用多节点 Switchboard Feed、延迟/争议窗口、紧急暂停和审计后的资金托管模型。
